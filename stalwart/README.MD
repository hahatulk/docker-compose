# Stalwart - свой SMTP сервер
Можно активировать премиум поменяя пару строк и сделав сборку вручную. <br>
Нужно около 8GB RAM для сборки

### Clone
```bash
git clone https://github.com/stalwartlabs/stalwart source
```
```bash
cd source
git checkout v0.16.27
```

### Сборка из исходников
```bash
bash build.sh
```

### Init
```bash
bash start.sh
```
